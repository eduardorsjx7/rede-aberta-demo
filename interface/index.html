    Como a observação funciona

    Duas pontes TCP encaminham exclusivamente para nossos servidores locais HTTP e HTTPS. Os bytes são observados antes da descriptografia TLS; não há captura de tráfego de outros sites. Somente envios com concordância são gravados. Cada envio guarda até 64 KiB do fluxo recebido, com limite de 100 envios por comparação.

    Os arquivos .bin guardam bytes de fluxo TCP, sem cabeçalhos IP/TCP: não são arquivos PCAP. Os dados ficam em dados/comparacoes/ e os detalhes na apresentação dependem de confirmação.
